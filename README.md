# NABU Social Foundation

Prototype ويب Mobile-first ذاتي التشغيل لأساس NABU الاجتماعي. افتح `index.html` في متصفح حديث.

## الحدود الحالية

لم يكن في المجلد مشروع أو backend سابق. تستخدم هذه النسخة بيانات تجريبية وحالة `localStorage` داخل المتصفح: المنشورات والتفاعلات والتعليقات والمتابعة تبقى في المتصفح نفسه فقط ولا تعمل بين مستخدمين حقيقيين. إدخال الصورة والفيديو واجهة تمهيدية ولا يخزن الملفات.

## ما يتوفر

- تغذية وتفاعل: منشورات، إعجاب، تعليقات، مشاركة وإنشاء منشور نصي أو وسائط.
- تنقل سفلي، بحث محلي، مجتمعات، رسائل، إشعارات، ملف شخصي وإعدادات.
